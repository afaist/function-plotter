# Function Plotter

Интерактивная программа для построения графиков математических функций.

![Linux](https://img.shields.io/badge/platform-linux-lightgrey)
![Windows](https://img.shields.io/badge/platform-windows-lightgrey)
![macOS](https://img.shields.io/badge/platform-macos-lightgrey)

## Возможности

- Построение графиков функций с адаптивной плотностью
- Поддержка производных: `deriv(sin(x))`
- Поддержка определённых интегралов: `integral(sin(x), 0, 3.14)`
- Поддержка полярных координат: `polar(cos(x), 0, 2*pi)`
- Поддержка параметрических кривых: `parametric(cos(t), sin(t), 0, 2*pi)`
- Квадратичные функции с интерактивными слайдерами: `a*x^2 + b*x + c`
- Кнопка «Авто» для автоматического извлечения коэффициентов из формулы
- Экспорт в CSV (один график или все) и PNG
- Сохранение и загрузка сессий в JSON
- Автоматическая загрузка последней сессии
- Поиск точек пересечения графиков
- Школьная сетка 1:1 для ОГЭ
- Шаблоны типовых функций (10 типов для ОГЭ)
- Масштабирование колесиком мыши и перемещение перетаскиванием

## Установка

### Сборка из исходного кода

```bash
git clone <repository-url>
cd function-plotter
cargo build --release
```

Готовый бинарный файл будет в `target/release/function-plotter`.

### Запуск

```bash
cargo run
```

## Использование

### Добавление графиков

1. Нажмите "+ Добавить график" в левой панели
2. Введите формулу в поле ввода (например: `sin(x)`, `x^2`)
3. Нажмите Enter или измените диапазон для пересчёта

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Ctrl+N` | Новый график |
| `Ctrl+O` | Загрузить сессию |
| `Ctrl+S` | Сохранить сессию |
| `Delete` | Удалить выбранный график |
| `R` | Сбросить масштаб |
| `F5` / `Ctrl+Enter` | Пересчитать графики |

### Квадратичные функции со слайдерами

Для квадратичных функций (`a*x^2 + b*x + c`) доступны интерактивные слайдеры:

1. Введите формулу: `2*x^2 + 3*x - 5`
2. Поставьте галочку «Слайдеры»
3. Нажмите «Авто» для извлечения коэффициентов `a`, `b`, `c`
4. Изменяйте слайдеры — график пересчитывается мгновенно

> **Важно:** после нажатия «Авто» используйте слайдеры для изменения коэффициентов. Формула обновится автоматически.

### Шаблоны функций

Кнопка «📋 Шаблоны» содержит 10 типовых функций для ОГЭ:
- Линейные: `x`, `2*x + 1`
- Квадратичные: `x^2`, `x^2 - 4`
- Обратная пропорциональность: `1/x`
- Корень: `sqrt(x)`
- Тригонометрические: `sin(x)`, `cos(x)`
- Показательная: `exp(x)`
- Модуль: `abs(x)`
- Дробь: `sin(x) / x`

### Примеры функций

**Базовые:**
- `sin(x)`, `cos(x)`, `tan(x)`
- `x^2`, `x^3`, `sqrt(x)`
- `exp(x)`, `log(x)`, `abs(x)`
- `sin(x) / x`

**Производные:**
- `deriv(sin(x))` — производная sin(x)
- `deriv(x^3 + 2*x)` — производная полинома

**Интегралы:**
- `integral(sin(x), 0, 3.14)` — определённый интеграл
- `integral(x^2, 0, 1)` — площадь под кривой

**Полярные координаты:**
- `polar(cos(x), 0, 2*pi)` — розетка

**Параметрические кривые:**
- `parametric(cos(t), sin(t), 0, 2*pi)` — окружность
- `parametric(cos(t)^3, sin(t)^3, 0, 2*pi)` — сердечко (кардиоида)

### Управление видом

- **Масштабирование:** колесико мыши (масштаб к курсору)
- **Перемещение:** зажать левую кнопку мыши и тянуть
- **Авто-масштаб Y:** чекбокс "Авто-масштаб Y" в левой панели
- **Школьная сетка 1:1:** чекбокс "Школьная сетка 1:1" — равные масштабы по X и Y (для ОГЭ)

### Экспорт

**CSV:**
- "Сохранить CSV (текущий график)" — экспорт одного графика в формате x,y
- "Сохранить CSV (все графики)" — экспорт всех графиков в формате x,y1,y2,...

**PNG:**
- "Сохранить PNG" — сохранение скриншота области графиков в формате PNG (область с осями и легендой)

### Сессии

**Сохранение:**
- "Сохранить сессию" — сохранение всех графиков и настроек в JSON
- `Ctrl+S` — быстрое сохранение в последний файл

**Загрузка:**
- "Загрузить сессию" — загрузка сессии из JSON файла
- `Ctrl+O` — быстрый выбор файла для загрузки

**Автозагрузка:**
- Чекбокс "Автозагрузка последней сессии" — автоматически загружает последнюю сессию при старте

## Помощь

### Частые вопросы

**Q: Почему график не обновляется при вводе формулы?**
A: После ввода формулы нажмите Enter или кликните вне поля ввода. Это вызовет пересчёт графика.

**Q: Как использовать слайдеры для квадратичных функций?**
A: Введите формулу вида `a*x^2 + b*x + c`, поставьте галочку «Слайдеры», нажмите «Авто» для извлечения коэффициентов. Затем изменяйте слайдеры — график пересчитается автоматически.

**Q: Почему коэффициент `c` не извлекается из формулы?**
A: Убедитесь, что между знаком и числом нет пробелов. Формула должна быть в формате `x^2+3*x-5` или `x^2 + 3*x - 5` (пробелы допустимы, но не обязательны).

**Q: Как построить график в полярных координатах?**
A: Используйте синтаксис `polar(функция, theta_min, theta_max)`. Пример: `polar(cos(x), 0, 2*pi)`.

**Q: Как построить параметрическую кривую?**
A: Используйте синтаксис `parametric(x_formula, y_formula, t_min, t_max)`. Пример: `parametric(cos(t), sin(t), 0, 2*pi)`.

**Q: Как сбросить масштаб?**
A: Нажмите клавишу `R` или кнопку «Сбросить масштаб» в правой панели.

**Q: Как найти точки пересечения графиков?**
A: Точки пересечения отображаются автоматически на графике. Кликните на график, чтобы выделить его и увидеть координаты точек пересечения.

## Формат сессии

Сессия сохраняется в JSON формате:

```json
{
  "version": 3,
  "graphs": [
    {
      "label": "f1",
      "formula": "sin(x)",
      "color": [100, 200, 255],
      "visible": true,
      "use_sliders": false,
      "slider_a": 1.0,
      "slider_b": 0.0,
      "slider_c": 0.0
    }
  ],
  "x_min": -10.0,
  "x_max": 10.0,
  "n_points": 500,
  "auto_y": true,
  "adaptive": false,
  "adaptive_tolerance": 0.01,
  "polar_mode": false,
  "school_grid": false,
  "viewport_x_min": -10.0,
  "viewport_x_max": 10.0,
  "viewport_y_min": -5.0,
  "viewport_y_max": 5.0
}
```

## Настройки приложения

Конфигурация хранится в:
- **Linux:** `~/.local/share/function-plotter/config.json`
- **Windows:** `%APPDATA%\function-plotter\config.json`
- **macOS:** `~/Library/Application Support/function-plotter/config.json`

```json
{
  "version": 3,
  "window_width": 1000.0,
  "window_height": 700.0,
  "auto_load_last_session": false,
  "theme": "dark"
}
```
